# ProgramaMinas

## Sobre o projeto

O ProgramaMinas é uma aplicação web desenvolvida para representar uma ONG
que oferece projetos gratuitos de tecnologia para mulheres.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro,
com foco em Single Page Application (SPA), manipulação do DOM,
validação de formulários, armazenamento local e organização modular
do código.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- LocalStorage
- Git e GitHub
